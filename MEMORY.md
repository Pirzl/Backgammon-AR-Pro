## Cómo juega el master L9-10

1. Generar secuencias legales completas para los dados.
2. Presort top-500 por heurística (`evaluatePosition`).
3. Score de candidato: `(nn * 50 * 0.40) + (heur * 0.60)`.
4. Blend final: `score * (1 - 0.4) + expectimaxChance(depth 2, oppWeight 0.4) * 0.4`.
5. Apertura experta (opening book L9-10, validación de legalidad, espejo para black).
6. ~~Skills tácticas + plan reflexivo (`scoreForSequenceBySkills`)~~ → **DESACTIVADO** (2026-08-03, `ENABLE_REFLECTIVE_OVERRIDE=false`): el pick es el blend base puro.
7. Fallback: `pickGreedyFallback` (nunca-skip); `expectimaxChance` envuelto en try/catch (degrade a score base).
